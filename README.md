# Subtrack - Subscription Tracker

A PWA to track subscriptions, costs and renewal dates.
Built with React (Vite), Tailwind CSS and Firebase (Auth + Firestore + Hosting).

**Live app:** https://webdev-c17c0.web.app

## Setup
1. `npm install`
2. Copy `.env.example` to `.env` and fill in your Firebase web app config values.
3. `npm run dev`

## Deploy
```
npm run build
firebase deploy
```
